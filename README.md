# Smart Expense Hub - Excel Tracker & Automated Due Date Notifier (PERN Stack)

A full-stack web application powered by **Neon PostgreSQL**, **Express.js**, **React**, and **Node.js**.

---

## 🚀 Quick Start Commands

In the root folder (`c:\Users\DELL\Sample1`):

1. **Install Dependencies**:
   ```bash
   npm run install:all
   ```

2. **Start Backend API** (Port 5000 - connects to Neon PostgreSQL):
   ```bash
   npm run server
   ```

3. **Start Frontend Dashboard** (Port 3000):
   ```bash
   npm run client
   ```
